# Next.js Interview Preparation

Next.js architecture, rendering paradigms, routing, and deployment.

## Topics to Cover
- App Router vs Pages Router
- Rendering strategies: SSR, SSG, ISR, Client-side rendering
- Server Components, Server Actions & Data Fetching
- Caching layers (Request memoization, Data Cache, Full Route Cache, Router Cache)
- Middleware, Authentication & Route Handlers
- Optimization (Images, Fonts, Scripts, Bundle analyzer)
