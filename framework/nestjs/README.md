# NestJS Interview Preparation

NestJS enterprise architecture, dependency injection, and modular backend design.

## Topics to Cover
- Dependency Injection (DI) & Inversion of Control (IoC)
- Architecture: Modules, Controllers, Providers, Services
- Middleware, Guards, Interceptors, Pipes & Exception Filters
- Microservices, message queues & WebSockets
- ORM integration (TypeORM, Prisma, Drizzle)
- Testing: Unit, Integration & E2E
