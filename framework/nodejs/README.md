# Node.js Interview Preparation

Node.js runtime, asynchronous architecture, concurrency, and backend design.

## Topics to Cover
- Event Loop phases (timers, pending, idle/prepare, poll, check, close)
- libuv, thread pool & asynchronous I/O
- Streams, Buffers & Pipeline processing
- Concurrency: Clustering vs Worker Threads vs Child Processes
- Memory leaks profiling & heap analysis
- Express.js architecture & middleware pipelines
