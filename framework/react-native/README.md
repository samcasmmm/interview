# React Native Interview Preparation

Mobile app architecture, native bridges, performance, and cross-platform patterns.

## Topics to Cover
- New Architecture: JSI, Fabric renderer, TurboModules, Bridgeless mode
- Old Architecture vs New Architecture (JSON Bridge bottlenecks)
- Hermes JS Engine & Bytecode compilation
- Animation performance: React Native Reanimated, Skia, 60/120 FPS UI thread
- Threading model: UI Thread, JS Thread, Shadow/Layout Thread
- Native modules & platform lifecycle (Android Activity/Fragment, iOS UIViewController)
