# AI & LLM Engineering Interview Preparation

Generative AI, LLMs, Retrieval-Augmented Generation (RAG), vector databases, and AI application architecture.

## Topics to Cover
- LLM fundamentals: Tokenization, context windows, temperature, top_p
- Prompt Engineering: Few-shot, Chain-of-Thought (CoT), ReAct pattern
- RAG (Retrieval-Augmented Generation): Embeddings, vector indexing (HNSW, IVFFlat), chunking strategies, hybrid search
- Vector Databases: pgvector, Pinecone, Qdrant, Chroma
- Agents & Tool Calling: LangChain, LlamaIndex, MCP (Model Context Protocol)
- Fine-tuning vs RAG vs Prompt Engineering
- LLM Evaluation, Guardrails & Latency/Cost Optimization
