# Algorithmic Coding Patterns

Standard problem-solving templates that solve hundreds of interview questions.

## Core 15 Patterns
1. **Two Pointers**: Opposite ends (sorted arrays) or same direction.
2. **Fast & Slow Pointers**: Cycle detection (Floyd's algorithm), middle of linked list.
3. **Sliding Window**: Fixed size vs dynamic size window for subarrays/substrings.
4. **Prefix Sum & Hash Map**: Subarray sum equals K, running totals.
5. **Monotonic Stack / Queue**: Next greater element, daily temperatures, largest rectangle in histogram.
6. **Merge Intervals**: Overlapping intervals, meeting rooms, insert interval.
7. **Cyclic Sort**: Finding missing/duplicate numbers in 1 to N range.
8. **In-place Reversal of a Linked List**: K-group reversal, palindrome linked list.
9. **Two Heaps**: Median of a data stream, sliding window median.
10. **Subsets & Permutations**: Backtracking templates.
11. **Modified Binary Search**: Search in rotated sorted array, peak element.
12. **Top 'K' Elements**: Min-Heap / Max-Heap / QuickSelect.
13. **0/1 Knapsack & Dynamic Programming**: DP states, memoization vs tabulation.
14. **Tree Traversals & Path Sums**: Preorder, Inorder, Postorder, Level-order, LCA.
15. **Graph Traversals**: BFS shortest path, DFS connected components, Topological Sort (Kahn's / DFS).
