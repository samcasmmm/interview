- **String Algorithms**: Knuth-Morris-Pratt (KMP & LPS array), Rabin-Karp rolling hash
- **Data Structure Internals**: Arrays, Linked Lists, BSTs, AVL/Red-Black, Heaps, Hash Tables, Tries
