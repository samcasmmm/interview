# Random Coding & Ad-Hoc Interview Challenges

Practical coding problems frequently given in live pair-programming and screening rounds.

## Problem Types
- **String & Text Processing**: Custom regex parsers, string compression, palindrome permutations, version compare
- **Math & Number Puzzles**: FizzBuzz variations, prime factorizations, Roman numeral conversions, bitwise tricks
- **Data Transformations**: Flatten nested arrays/objects, deep clone implementations, grouping and aggregation
- **Simulation & Game Logic**: Tic-tac-toe, Snake game, Conway's Game of Life
- **Custom Data Structures**: LRU Cache, LFU Cache, Rate limiter token bucket, MinStack
