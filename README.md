# 🎯 Interview Preparation Hub

A structured repository of interview study guides, categorized by language, framework, system design, coding patterns, and engineering domains.

---

## 📂 Folder Structure & Navigation

### 1. 🔤 Languages (`language/`)
- [**JavaScript**](./language/javascript/README.md) — Event loop, closures, prototypes, V8 engine, async runtime.
- [**Python**](./language/python/README.md) — Memory model, GIL, decorators, generators, asyncio, dunder methods.
- [**SQL & Relational DBs**](./language/sql/README.md) — Execution order, indexing, window functions, CTEs, transactions & MVCC (See also [postgres_sql.md](./postgres_sql.md)).

### 2. ⚡ Frameworks & Runtimes (`framework/`)
- [**React**](./framework/react/README.md) — Virtual DOM, Fiber, hooks, re-rendering optimization, RSC, Concurrent Mode.
- [**Next.js**](./framework/nextjs/README.md) — App Router, SSR/SSG/ISR, Server Actions, 4-tier caching, route handlers.
- [**Node.js**](./framework/nodejs/README.md) — Event loop phases, libuv, streams, buffers, clustering, worker threads.
- [**NestJS**](./framework/nestjs/README.md) — Architecture, DI/IoC, modules, guards, interceptors, microservices.
- [**React Native**](./framework/react-native/README.md) — JSI, Fabric renderer, TurboModules, Hermes, UI thread 60fps animations.

### 3. 🧩 Core Engineering Domains
- [**DSA (Data Structures & Algorithms)**](./dsa/README.md) — Algorithms, data structures, and core interview patterns (sliding window, two pointers, DP, trees, graphs).
- [**System Design**](./system-design/README.md) — High-Level Design (HLD), Low-Level Design (LLD), caching, scalability, distributed systems.
- [**AI & LLMs**](./ai/README.md) — Generative AI, RAG, vector databases (pgvector), prompt engineering, AI agents.
- [**Other Tech & DevOps**](./other-tech/README.md) — Docker, Kubernetes, CI/CD, AWS, Redis, networking, protocols.
- [**Basic & Generic (Behavioral)**](./basic-generic/README.md) — HR questions, STAR method, conflict resolution, technical leadership.
